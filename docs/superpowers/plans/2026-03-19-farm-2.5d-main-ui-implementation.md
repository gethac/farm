# Farm 2.5D Main UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保留现有全部农场、任务、背包、好友、排行、通知能力的前提下，将移动端首页重构为 2.5D 游戏化农场主界面。

**Architecture:** 保留现有 `App.tsx` 数据加载、`game-store` 状态语义和 `farm:operate` 事件流，只重构 `AppShell`、`FarmScreen` 及相关视图组件的布局与样式。农场主界面将改为“场景层 + HUD 层 + 浮层层”的结构，同时让非农场一级模块继续沿用 `activeTab` 切换，但以更游戏化的 sheet/drawer 容器承载。

**Tech Stack:** React 19、TypeScript、Vite、Vitest、全局 CSS
